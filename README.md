### 🚀 Sobre mim

Sou desenvolvedor frontend desde 2023, com experiência prática no desenvolvimento de aplicações usando tecnologias modernas como **Angular** e **Next.js**, aplicando boas práticas de estruturação, testes e performance.

Atualmente atuo na Venture Miner, onde contribuo com soluções focadas em organização de código, experiência do usuário e integração entre sistemas.

Também tenho explorado o uso de **ferramentas de inteligência artificial**, como **Vercel AI** e **modelos de linguagem (LLMs)**, criando interfaces dinâmicas e inteligentes.
